# لوميـرا بيوتي — قالب متجر مستحضرات تجميل عربي

قالب متجر إلكتروني كامل باللغة العربية (RTL) لمتجر مستحضرات العناية والمكياج، مبني بـ React + TypeScript + Vite، مع الطلب عبر واتساب بدلاً من بوابات الدفع.

## الأوامر

```bash
npm install        # تثبيت الحزم
npm run dev        # تشغيل بيئة التطوير
npm run build      # بناء نسخة الإنتاج إلى dist/
npm run preview    # معاينة نسخة الإنتاج
npm run lint       # فحص الكود
```

## هيكل المشروع

```
public/images/            صور المنتجات (تنتهي بمعرّف صورة Pexels)
src/
  config/site.ts          الإعدادات المركزية (الاسم، واتساب، الدول، العملات)
  data/catalog.ts         الأقسام والمنتجات والآراء والبانرات
  store/StoreContext.tsx  السلة والمفضلة والدولة (محفوظة في localStorage)
  components/             الهيدر، الفوتر، بطاقة المنتج، الأيقونات...
  pages/                  الصفحات (الرئيسية، المتجر، المنتج، السلة...)
```

## التخصيص — أهم 3 ملفات

### 1) معلومات المتجر: `src/config/site.ts`
غيّر هنا اسم المتجر، رقم الواتساب (صيغة دولية بدون +)، البريد، ساعات العمل، وروابط التواصل الاجتماعي.

### 2) الدول والعملات والأسعار: `src/config/site.ts`
كل دولة تحتوي: سعر الصرف من الدينار الأردني `rate`، رسوم الشحن `deliveryFee`، وحد الشحن المجاني `freeDeliveryThreshold`.

لتغيير العملة الأساسية، عدّل `rate` في كل الدول (قيمة 1 لدولة الأساس) والأسعار في `catalog.ts`.

### 3) المنتجات والأقسام: `src/data/catalog.ts`
- `categories`: الأقسام الظاهرة في الصفحة الرئيسية والفوتر.
- `products`: كل منتج يحتوي: `name` (اسم عربي)، `price` (بالعملة الأساسية)، `image` (معرّف الصورة)، `badge` (`new` / `sale` / `bestseller`).
- `testimonials`: آراء العميلات.
- `banners`: بانرات الصفحة الرئيسية.

## الصور

الصور محفوظة في `public/images/<id>.jpg`، وهي من Pexels (ترخيص مجاني للاستخدام التجاري). لاستبدال صورة منتج، ضع الصورة الجديدة داخل `public/images` ثم عدّل المعرّف في `catalog.ts`.

لتنزيل صور إضافية من Pexels:
```bash
node C:\Users\zaida\AppData\Local\Temp\opencode\img_dl\dl.js D:\cosmitc\public\images
```
مع إضافة المعرّفات إلى `ids.txt` في نفس مجلد السكربت (تعرض الصور كـ `https://images.pexels.com/photos/<id>/pexels-photo-<id>.jpeg`).

## الطلب عبر واتساب

السلة وصفحة المنتج تنشئان رسالة جاهزة وتفتح `wa.me` برقم واتساب المحدد في `siteConfig.whatsappNumber`. لا يوجد أي كود دفع — فقط رسالة تأكيد تُرسل يدوياً.

## ملاحظات

- الواجهة عربية RTL بالكامل؛ لا تستخدم النصوص الإنجليزية كعناصر ظاهرة.
- السلة والمفضلة والدولة تُحفظ في `localStorage`.
- المنشور النهائي يُنشر ببساطة كمجلد `dist` ثابت (أي استضافة: Netlify، Vercel، GitHub Pages...).
